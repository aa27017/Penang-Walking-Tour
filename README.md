# 歴史散策ウォーキングツアー（ペナン／マラッカ）PWA

ペナン島ジョージタウンとマラッカ（ムラカ）の世界遺産地区を、日本語の解説を読み・聞きながら徒歩で回るためのWebアプリです。iPhoneのSafariで「ホーム画面に追加」すると、ふつうのアプリのように全画面で使えます。ビルド作業は不要で、静的ファイルをそのまま GitHub Pages に置くだけで動きます。

最初に開くと「どの町を歩きますか？」と都市を選ぶ画面が出ます。選んだ都市は端末に保存され、画面左上の都市名ボタンでいつでも切り替えられます。

## できること（両都市共通）

| 機能 | 内容 |
|---|---|
| 都市の選択 | ペナン／マラッカを選択（localStorageに保存）。訪問記録やスタンプは都市ごとに別々に保存 |
| 地図 | Leaflet + OpenStreetMap。全スポットのピン（番号付き）と、推奨ルートの線（実際の道に沿った徒歩ルート） |
| ツアー | コースA／B／C を推奨順に表示。「次へ」で進むと訪問済みとして記録 |
| スポット詳細 | 解説（300〜500字）、歴史的背景、見どころ、所要時間、入場料、営業時間、写真撮影ポイント、注意事項、出典、その場所がどの時代のものかを示す「時代チップ」 |
| 現在地 | 次のスポットまでの距離と方角（矢印をタップするとコンパス表示に切り替え） |
| 近接通知 | スポットの約50m以内に近づくとバナーを表示（設定でON/OFF）。バナーの「▶ 聞く」で、そのスポットの音声ガイドがすぐ始まります |
| 音声ガイド | 再生／一時停止、前の文・次の文、速度（0.75／1／1.25／1.5倍）、読んでいる文をハイライト。文をタップするとそこから読み直します。こどもモードはゆっくりめ |
| 年表 | 都市の歴史を時代ごとに整理し、各出来事から関連スポットへ移動できます。こどもモードでは物語風（マラッカは「4つの国がやってきた町」） |
| 用語集 | 各都市20語 |
| 実用情報 | 暑さ・スコール対策、宗教施設のマナー、トイレ・休憩、Grab、緊急連絡先（マラッカはトライショーの料金交渉も） |
| オフライン | アプリ本体・全都市の解説・写真は自動でキャッシュ。地図は都市ごとに「地図を保存」ボタンで事前に取得 |
| こどもモード | こども向けの文章（100〜150字、小学2年生までに習う漢字以外はふりがな付き）、「みつけてみよう！」クイズ、スタンプラリーと認定証（「ペナン探検マスター」「マラッカ探検マスター」）、休けいカード。ペナンは壁画さがしも |

## コース

### ペナン（ジョージタウン）

- **A：ヘリテージ王道コース**（約3.5〜4時間＋休憩、歩行約5km）：聖母被昇天大聖堂 → 州立博物館 → セントジョージ教会 → シティホール → エスプラネード → コーンウォリス要塞 → 時計塔 → プラナカン・マンション → リトルインディア → 観音寺 → マハマリアマン寺院 → カピタン・クリン・モスク → 孫文ゆかりの地 → ヤップ・コンシ → アチェ通りモスク → クー・コンシ → ストリートアート → クラン・ジェッティ（最初のE&Oホテル／ブルー・マンションは寄り道）
- **B：短縮コース**（約1.5〜2時間、歩行約1.8km）：観音寺 → マハマリアマン寺院 → カピタン・クリン・モスク → 孫文ゆかりの地 → クー・コンシ → ストリートアート → クラン・ジェッティ
- **C：郊外スポット**（Grab）：極楽寺、ペナンヒル

### マラッカ

- **A：世界遺産王道コース**（約3.5〜4時間＋休憩、歩行約2.6km）：キリスト教会 → 時計台 → ヴィクトリア女王の噴水 → スタダイス → スルタン・パレス博物館 → サンチャゴ砦（ア・ファモサ） → セントポールの丘 → 海洋博物館 → リバークルーズ乗り場 → ババ・ニョニャ・ヘリテージ博物館 → ヒーレン通り → ジョンカー通り → カンポン・クリン・モスク → ヴィナヤガ・ムーティ寺院 → チェンフンテン寺院
- **B：短縮コース**（約1.5〜2時間、歩行約1.7km）：キリスト教会 → スタダイス → ア・ファモサ → セントポールの丘 → ジョンカー通り → カンポン・クリン・モスク → チェンフンテン寺院
- **C：少し離れたスポット**（徒歩約1.6km＋Grab）：カンポン・モルテン → セントピーター教会 → ハン・リーポーの井戸 → ブキッ・チナと宝山亭 → ポルトガル村（Grab）

順番は、OpenStreetMapで確かめた座標と、OSMの道路データによる実際の徒歩距離をもとに決めています（マラッカAは「オランダ広場 → 丘と砦 → 川 → チャイナタウン」の流れを保ったうえで最短になる順）。

## フォルダ構成

```

├── sw.js                   Service Worker（オフライン対応。cities.json の全都市を自動でキャッシュ）
├── favicon.ico
├── css/style.css           デザイン（セーフエリア対応・ダークモード対応）
├── js/app.js               アプリ本体（プレーンJavaScript、ビルド不要）
├── data/
│   ├── cities.json         ★都市の一覧（名前・地図の中心・オフライン保存範囲など）
│   ├── penang/
│   │   ├── spots.json      スポットとコース
│   │   ├── glossary.json   用語集
│   │   ├── info.json       実用情報・緊急連絡先
│   │   └── timeline.json   年表（任意）
│   └── melaka/             （同じ4ファイル）
├── images/
│   ├── penang/             スポット写真（Wikimedia Commons、ライセンスはspots.jsonに記載）

├── icons/                  アプリアイコン（apple-touch-icon含む）
└── vendor/leaflet/         Leaflet 1.9.4（オフラインでも動くよう同梱）
```

## パソコンで動かしてみる

Service Worker と位置情報は `http://localhost` か `https://` でしか動かないため、ファイルをダブルクリックで開くのではなく、簡易サーバーを使います。Macなら最初からある Python で動きます。

```bash
cd ~/Documents/penang-walking-tour
```

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。止めるときは Ctrl+C です。

## GitHub Pages で公開する手順

1. GitHub にログインし、右上の「＋」→「New repository」を選びます。
2. Repository name を入力し、**Public** を選んで「Create repository」を押します（無料プランの GitHub Pages は公開リポジトリが必要です）。
3. このフォルダの**中身**をアップロードします（フォルダごとではなく、中のファイルとフォルダを選びます）。
   - 作成したリポジトリのページで「uploading an existing file」をクリック
   - Finder で `penang-walking-tour` フォルダを開き、中身（`index.html`、`data`、`js` など）をすべて選んでドラッグ＆ドロップ
   - 「Commit changes」を押す
   - ※ `.nojekyll` は隠しファイルです。Finder で ⌘+Shift+. を押すと表示されます。

   > フォルダごとアップロードすると、`index.html` がフォルダの中に入るため、`https://ユーザー名.github.io/リポジトリ名/` を開くと **404** になります。その場合は `https://ユーザー名.github.io/リポジトリ名/penang-walking-tour/` で開けます。

4. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
5. 「Build and deployment」の Source で **Deploy from a branch** を選び、Branch を **main**、フォルダを **/(root)** にして「Save」を押します。
6. 1〜2分待つと、ページ上部に公開アドレスが表示されます。

### すでに公開しているペナン版を更新する場合（今回のマラッカ追加）

ファイルの置き場所が変わったので、次のようにしてください（GitHubのブラウザ画面での手順です）。

1. 公開中のフォルダ（例：`penang-walking-tour` フォルダ）を開き、「Add file」→「Upload files」から、新しいフォルダの中身をすべてドラッグして上書きアップロードします。
2. もう使わない古いファイルを削除します：`data/spots.json`、`data/glossary.json`、`data/info.json`、`images/spots/` フォルダ（残っていても動きますが、混乱のもとになります）。
3. iPhoneでアプリを開き直します。Service Worker の `VERSION` を `v2.0.0` に上げてあるので、新しいファイルに自動で入れ替わります（反映されない場合は、アプリを完全に終了してから2回ほど開き直してください）。
4. 以前のペナンの訪問記録は、初回にペナンを選んだときに自動で引き継がれます。

## iPhone でホーム画面に追加する手順

1. iPhone の **Safari** で、公開アドレスを開きます（Chrome などではなく Safari を使ってください）。
2. 画面下の **共有ボタン**（四角から上向き矢印が出ているアイコン）をタップします。
3. メニューを上にスクロールして **「ホーム画面に追加」** をタップします（見つからない場合は、いちばん下の「アクションを編集」から追加できます）。
4. 名前（「歴史散策」）を確認して、右上の **「追加」** をタップします。
5. ホーム画面にできたアイコンから起動すると、Safariのアドレスバーがない全画面表示になります。

### 出発前にやっておくこと（Wi-Fiのある場所で）

1. ホーム画面のアイコンから一度アプリを起動します（両都市の解説・写真がまとめてキャッシュされます）。
2. 行く都市を選び、「情報・設定」タブ →「地図を保存」を押して「保存済み」の枚数が全枚数と同じになるまで待ちます（ペナン172枚、マラッカ96枚）。両方行く場合は、都市を切り替えてそれぞれ保存します。
3. 地図タブの ◎ ボタンを押して、位置情報の利用を「許可」します。
4. 必要なら「近づいたら知らせる」をONにします。
5. 機内モードにして、アプリが開けること・地図が表示されることを確かめておくと安心です。

### iPhone での注意

- **位置情報**：許可しなかった場合は、iPhoneの「設定」→「プライバシーとセキュリティ」→「位置情報サービス」→「Safariのサイト」で「使用中のみ」にします。
- **コンパス**：次のスポットまでの矢印をタップすると、「動きと方向」へのアクセス許可を求められます。許可すると矢印が進む方向を指します。
- **近接通知と音声ガイド**：アプリを開いている間だけ動きます。iPhoneでは、音声はボタンをタップしたときにしか再生できない決まりがあるため、近づいても自動では読み上げず、バナーの「▶ 聞く」をタップすると始まります。
- **音声ガイド**：消音モード（マナーモード）だと音が出ないことがあります。日本語の声は iPhone の「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」で追加・変更できます。一時停止すると、再開時はその文の頭から読み直します。
- **データの保存**：訪問記録やスタンプは端末の中（localStorage）に保存されます。iOSは、ホーム画面に追加したアプリを長い間使わないとデータを消すことがあります。旅行の直前にもう一度開いておきましょう。

## 都市を追加する方法

ほかの都市（例：クアラルンプール、イポーなど）も、コードを書き換えずにデータを足すだけで追加できます。

1. **フォルダを作る**：`data/<都市id>/` と `images/<都市id>/` を作ります。都市idは半角英小文字（例：`ipoh`）。
2. **4つのファイルを用意する**：`data/melaka/` の4ファイルをコピーして、中身を書き換えるのが簡単です。
   - `spots.json`（必須）：スポットとコース。書き方は下の「spots.json の項目」を参照
   - `glossary.json`（必須）：用語集
   - `info.json`（必須）：実用情報・緊急連絡先
   - `timeline.json`（任意）：年表。無い場合、その都市では年表タブに用語集だけが表示されます
3. **`data/cities.json` に1件追加する**：

   ```json
   {
     "id": "ipoh",
     "name": "イポー",
     "sub": "旧市街",
     "place_label": "イポー",
     "title": "イポー歴史散策",
     "kids_title": "イポーたんけん",
     "master": "イポー<ruby>探検<rt>たんけん</rt></ruby>マスター",
     "cover": "images/ipoh/xxx.jpg",
     "center": [緯度, 経度],
     "tile_areas": [
       { "name": "旧市街", "bbox": [南の緯度, 西の経度, 北の緯度, 東の経度], "zooms": [14, 15, 16, 17] }
     ]
   }
   ```

   - `master` はスタンプラリーの認定証に出る称号です（ルビ可）。
   - `tile_areas` はオフライン保存の範囲です。OpenStreetMap の規約（ズーム13以上で250枚を超える一括取得は禁止）を守るため、アプリは1都市250枚までしか取得しません。範囲はツアーに必要な部分に絞ってください。
4. **`sw.js` の `VERSION` を上げる**（例 `'v2.1.0'`）。Service Worker は `cities.json` を読んで、新しい都市のデータと写真を自動でキャッシュ対象にします。
5. **確かめる**：ローカルで開いて都市選択に新しい都市が出ること、地図・ツアー・詳細・年表が表示されることを確認します。

### spots.json の項目

| 項目 | 説明 |
|---|---|
| `id` | 半角英数字の一意な名前（例 `"khoo"`） |
| `category` | 分類（自由。例 `colonial` / `religion` / `chinese` / `other`） |
| `eras` | このスポットが関わる時代のidの配列（`timeline.json` の `eras[].id`）。詳細画面の「時代チップ」と、こども用年表の「この時代のスポット」に使われます |
| `name` | `{ "ja": 日本語名, "en": 英語名, "local": 現地表記 }` |
| `lat`, `lng` | 緯度・経度（OpenStreetMapで右クリック→「この場所を表示」で調べられます） |
| `summary` | 一行説明 |
| `description` | 解説（300〜500字が目安）。音声ガイドは「。」「！」「？」で文を区切って読み上げます |
| `background` | 歴史的背景 |
| `highlights` / `photo_spots` / `cautions` | 見どころ／撮影ポイント／注意事項（文字列の配列） |
| `duration_min` | 所要時間の目安（分） |
| `fee` / `hours` | `{ "text": 表示する内容, "ref": 補足（任意）, "verified": true/false }`。`verified:false` の場合は画面に「要確認」と表示されます |
| `transport` | （任意）アクセスの目安。Grab移動のコースで表示されます |
| `sources` | 出典 `[{ "title": ..., "url": ... }]` |
| `verified` | 座標と内容を確認済みかどうか |
| `photo` | `{ "src": "images/<都市id>/xxx.jpg", "credit": 作者, "license": "CC BY-SA 4.0", "license_url": ..., "source_url": ... }`。写真がない場合は `null`（プレースホルダー表示） |
| `kids_text` | こども用の文章（100〜150字）。ふりがなは `<ruby>漢字<rt>かんじ</rt></ruby>` と書きます |
| `kids_quiz` | `{ "question": 問題, "answer": 答え }`（どちらもルビ可） |
| `murals` | （任意）壁画さがしリスト `[{ "id", "name", "hint_ja", "lat", "lng" }]`。こどもモードの地図にも表示されます |

コースは `courses` の `stops` に `{ "id": "スポットのid", "stay_min": 滞在分 }` を並べます。`"optional": true` で「寄り道」、`"note"` で補足。`rests` はこどもモードの「休けいしよう」カード（`after` に指定したスポットのあとに表示）、`"transport": true` はGrab移動前提のコースです。ルートの線（`route`）は自動では作られません。順番を大きく変えた場合は `route` を削除してください（線が出なくなるだけで、ほかは動きます）。

### timeline.json の項目

- `title` / `kids_title` / `kids_intro`：年表とこども用物語のタイトル・導入文
- `eras`：時代の配列。`id`、`title`、`period`（期間の表示）、`color`、`summary`、`kids_title`、`kids_text`
- `events`：出来事の配列。`year`（表示用の文字列）、`era`（時代id）、`title`、`text`、`spots`（関連スポットidの配列）

### アプリ本体（HTML/CSS/JS）を変更したとき

`sw.js` の先頭にある `VERSION` の値を上げてください。上げないと、iPhoneに古いファイルが残ることがあります。データ（JSON）はネットワーク優先で読み込むので、JSONの修正だけなら次回起動時に反映されます。

## 動作確認の結果（2026年11月21日）

- macOS 上のローカルサーバー＋Chromium系ブラウザ（スマホ幅 375×812）で確認しました。
  - **都市選択**：初回の都市選択画面、都市の切り替え、選んだ都市の保存
  - **以前の記録の引き継ぎ**：旧バージョンのペナンの訪問記録とコース選択が引き継がれること
  - **マラッカ**：地図・ルート・20か所のピン、ツアー、詳細画面と写真、こどもモード（ふりがな・クイズ・スタンプ・「マラッカ探検マスター」認定証・休けいカード）、年表（おとな用・こども用物語）、地図タイル96枚の保存
  - **音声ガイド**：再生、一時停止、次の文、速度変更、文ごとのハイライト、自動で次の文へ進むこと、到着通知の「▶ 聞く」からの再生（位置情報は擬似的に入れて確認）
  - **ペナン（既存機能）**：地図・ツアー・コース切り替え・壁画さがし・休けいカード・用語集・年表・実用情報
  - **オフライン**：サーバーを止めた状態で、マラッカ・ペナンの両方が起動し、都市の切り替え、写真、保存済みの地図タイルが表示されること
- Lighthouse は、この作業環境に Node.js と Chrome がないため実行できていません（Lighthouse 12以降はPWAカテゴリ自体が廃止）。インストール条件（manifest、アイコン実寸、Service Worker、オフラインでのstart_url）は個別に確認済みです。
- 実機（iPhone Safari）での確認はまだです。とくに位置情報・コンパス・音声（iOSの声と一時停止の挙動）は、出発前に実機で試してください。
